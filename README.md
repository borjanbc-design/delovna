# Фотографии

Тука одат **само вистински фотографии од Get café** — Аеродром и Кисела Вода.
Никакви стокови слики од други локали.

Додај ги со точно овие имиња и сајтот ќе ги подигне сам, без промена во кодот:

| Фајл | Каде се појавува | Препорачано |
|------|------------------|-------------|
| `hero-1.jpg` | Хиро слајд 1 | пејзажна, ≥ 2000px широка |
| `hero-2.jpg` | Хиро слајд 2 | пејзажна, ≥ 2000px широка |
| `hero-3.jpg` | Хиро слајд 3 | пејзажна, ≥ 2000px широка |
| `interior.jpg` | „Нашата приказна“ — голема | портретна 4:5, ≥ 1200px |
| `detail.jpg` | „Нашата приказна“ — мала | квадратна, ≥ 900px (детаљ: шолја, бар, рака) |
| `ambient.jpg` | Позадина зад цитатот | пејзажна, ≥ 2000px, потемна |
| `aerodrom.jpg` | Картичка за локација + избор во резервација | пејзажна, ≥ 1000px |
| `kisela-voda.jpg` | Картичка за локација + избор во резервација | пејзажна, ≥ 1000px |

Додека фајлот го нема, на негово место стои брендирана површина (градиент во
пурпурно + суптилна текстура) — не празен правоаголник и не грешка во конзолата.
Значи сајтот изгледа завршено и пред да ги додадеш фотографиите.

Фотографиите се вчитуваат мрзливо (300px пред да влезат во екранот) преку
`data-bg` во `index.html` и модулот `Backgrounds` во `script.js`.
